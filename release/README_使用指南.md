# FaceGuard 使用指南

## 一、安装

1. 双击下载的 `FaceGuard-Setup.exe`
2. 按向导点击「下一步」完成安装（默认安装到 `C:\Program Files\FaceGuard`）
3. 安装结束时会自动写入开机自启注册表项
4. 勾选「立即注册人脸」可直接进入注册步骤

## 二、首次注册人脸（必做）

FaceGuard 需要先认识你的脸才能解锁。

1. 从「开始菜单 → FaceGuard → FaceGuard 注册人脸」打开
2. 输入你的名字（任意，用作标签）
3. 正对摄像头，缓慢转头，采集 8 张不同角度
4. 看到「注册完成」即成功

> 注册的人脸数据保存在 `%APPDATA%\FaceGuard\data\faces.npz`，仅本地存储，不上传。

## 三、日常使用

安装后 FaceGuard **开机自动启动并常驻后台**，你无需任何操作：

- **锁屏后解锁**：锁屏状态下正对摄像头，识别到本人后自动唤醒解锁
- **识别画面**：屏幕右上角会显示摄像头画面，带人脸轮廓、扫描线等特效
- **身后有人**：身后出现其他人脸时立即声光提醒 + 邮件告警
- **离开自动锁屏**：离开摄像头 N 秒后自动锁屏，再 M 秒未解锁则休眠

## 四、配置邮箱告警（重要）

失败抓拍和入侵提醒需配置邮箱授权码：

1. 登录 [QQ 邮箱](https://mail.qq.com) → 设置 → 账户
2. 找到「POP3/IMAP/SMTP」服务，开启「IMAP/SMTP 服务」
3. 按提示用手机发送短信获取**授权码**（16 位字母，非登录密码）
4. 打开「开始菜单 → FaceGuard → FaceGuard 设置」
5. 填入发件邮箱 `1247053973@qq.com` 和授权码，保存

## 五、所有可调参数

在「FaceGuard 设置」面板中可调：

| 参数 | 说明 | 默认值 |
|---|---|---|
| 置信度阈值 | 相似度高于此值判定为本人，越低越易通过 | 0.55 |
| 确认帧数 | 连续命中 N 帧才解锁，越大越稳 | 3 |
| 摄像头序号 | 多摄像头时切换 | 0 |
| 冷却秒数 | 同一告警最小间隔 | 60 |
| 离开后锁屏(秒) | 离开多久自动锁屏 | 300 |
| 锁屏后休眠(秒) | 锁屏多久未解锁则休眠 | 300 |
| 身后入侵守护 | 开关 | 开 |
| 注册表自启 | 开关 | 开 |
| 识别画面叠加 | 开关 | 开 |

配置文件位置：`%APPDATA%\FaceGuard\config.json`，也可直接编辑。

## 六、卸载

「开始菜单 → FaceGuard → 卸载 FaceGuard」，或在「设置 → 应用」中卸载。
卸载时会询问是否删除用户数据（人脸库 / 配置 / 抓拍照片）。

## 七、常见问题

**Q: 解锁不灵敏？**
A: 在设置中降低「置信度阈值」(如 0.45)，或减少「确认帧数」(如 2)。注册时多采几张不同光照下的。

**Q: 摄像头打不开？**
A: 检查摄像头是否被其它程序(会议软件)占用；在设置中切换「摄像头序号」。

**Q: 没收到告警邮件？**
A: 确认已填入 QQ 邮箱**授权码**（非登录密码）；检查邮箱垃圾箱。

**Q: 重启后没自启？**
A: 检查注册表 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 是否有 FaceGuard 项；杀毒软件可能拦截，加白名单。

## 八、日志与抓拍

- 日志：`%APPDATA%\FaceGuard\logs\faceguard.log`（按天轮转，保留 7 天）
- 抓拍照片：`%APPDATA%\FaceGuard\captures\`（识别失败 / 入侵时保存）
